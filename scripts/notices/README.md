# License notice inputs

`npm run notices:generate` reads the full, locked Cargo dependency graph and copies license, notice, copyright, and attribution files from Cargo's local crate sources. Run `cargo fetch --locked` first on a fresh checkout. `npm run notices:check` compares the generated artifact without changing it. Neither command compiles code or changes the lockfile.

Some published crates omit their repository-level license files. `sources.json` records the exact package versions, primary upstream source URLs, SHA-256 checksums, and cached text used for those exceptions. Napi and html5ever repository commits come from each published crate's `.cargo_vcs_info.json`. The Neon and Xray MIT notices preserve origins credited in the upstream napi README files. A dependency update must review these version-specific exceptions; stale entries or missing notices fail generation.

For `fxhash` and `mac`, the published source declares an Apache-2.0 alternative without shipping the full license. Their original source/README notice is retained together with the standard Apache-2.0 text published in the locked `bitflags` crate. `selectors` ships its MPL-2.0 source notice without the full license; the identical license terms are reproduced from the locked `cssparser` crate. The generator also includes nested license files, including the Unicode notice in `regex-syntax`.

Cached texts are upstream legal notices, including original public author and copyright attributions. Preserve those attributions when refreshing the cache. The generated artifact intentionally contains no local registry paths, timestamps, or machine identifiers.

`runtime.json` separately records reviewed standard-library notices for Rust 1.96.1, 1.97.1, and 1.99.0, the releases used for the existing native builds. Their original `COPYRIGHT`, `LICENSE-MIT`, `LICENSE-APACHE`, `library/compiler-builtins/LICENSE.txt`, `license-metadata.json`, and `library/Cargo.lock` were obtained from the corresponding upstream release tags. Only standard-library in-tree attributions are retained from the copyright metadata. Published dependency source archives were checked against those lockfile checksums before retaining their legal notices. The union includes other targets and test dependencies so platform-specific subsets remain covered. Identical legal texts are cached once as `runtime-<digest>.txt`; no HTML documentation or Rust implementation sources are copied here. The check command rejects a compiler release that has no reviewed runtime notice snapshot.

To review another compiler release, obtain those same small upstream metadata/license files, collect each external standard-library package's original notices from its checksum-verified archive, and update `runtime.json` plus the checksum/provenance entries in `sources.json`. Packages that omit standalone licenses use their pinned upstream repository notices. `r-efi` and `r-efi-alloc` offer an Apache-2.0 alternative; the cache preserves their original AUTHORS and licensing statements together with that complete license text. Regenerate the artifact and review the changed notices before shipping binaries built with the new compiler.
